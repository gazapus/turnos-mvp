# Inicio y navegación

## Cómo entrar

Usá tu mail y contraseña en la pantalla de inicio de sesión. Si las credenciales no son correctas, el sistema muestra un error genérico (no indica si el mail existe). Después de tres intentos fallidos con el mismo mail e IP, el acceso se bloquea 10 minutos.

Al entrar, te lleva al panel de tu rol:

- Administrador: Usuarios
- Recepcionista: Agenda
- Médico: Agenda

Para salir, usá el control de perfil cuando esté disponible. En esta versión el perfil aún no abre un menú completo.

## Menú según tu rol

El menú lateral muestra solo lo que tu rol puede usar:

- **Agenda** — Administrador, Recepcionista y Médico
- **Consultorios** — Administrador y Recepcionista
- **Pacientes** — Administrador y Recepcionista (pantalla aún no disponible)
- **Usuarios** — solo Administrador (pantalla aún no disponible)
- **Sala de espera** — Administrador y Recepcionista (pantalla aún no disponible)

El médico ve únicamente Agenda.

En escritorio podés achicar el menú para ver solo iconos. En pantallas chicas el menú se abre como cajón desde el botón superior izquierdo.

Hay una sola Agenda (`/agenda`) para todos los roles. No existe una agenda aparte “mi agenda”.

## Botón AYUDA BOT

Abajo a la derecha está **AYUDA BOT**. Abrilo para preguntar cómo usar esta aplicación (agenda, confirmar, cancelar, consultorios) o qué significan términos como primer turno, estados o especialidades. No responde temas ajenos al sistema ni consulta turnos o pacientes reales.
